## 八股整理标准

每道题尽量保留四层内容：

1. `先讲人话`：先用生活化语言解释，不默认你懂术语。
2. `前置概念`：把这道题必须懂的基础概念先补齐。
3. `30 秒短答`：面试时先给结论。
4. `1-2 分钟标准回答`：可直接复述的完整答案。
5. `原理拆解`：能应对技术追问。
6. `结合项目怎么讲`：把八股落到真实服务、项目或简历经历。

## 小白友好原则

- 先建立直觉，再背答案。
- 每次只引入少量新概念，避免术语连环套。
- 遇到陌生词，先补定义，再讲它解决什么问题。
- 同一道题保留两版答案：理解版和面试口述版。
- 可以先不追求源码级细节，优先把主流程和常见追问讲稳。

## 复习状态

- `未整理`：只有题目或零散材料。
- `已成稿`：有完整答案，但还没压缩成口述版。
- `可复述`：能在 1 到 2 分钟讲清楚。
- `需强化`：追问容易卡住，或项目结合不够实。
