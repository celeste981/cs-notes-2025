点击式流程拆解

第 1 步

应用工程

Message Role、Context、Structured Output、Streaming、成本。

为什么要记：先会搭上下文。

第 2 步

推理规划

Chain vs Agent、Observation、ReAct、Reflection。

为什么要记：理解循环。

第 3 步

工具系统

Function Calling、Tool Schema、并行工具和权限。

为什么要记：理解行动边界。

第 4 步

知识系统

Embedding、RAG、Memory、Hybrid Search、Eval。

为什么要记：理解知识来源。

第 5 步

生产安全

Observability、成本、可靠性、Prompt Injection、PII。

为什么要记：理解上线风险。

容易说错

  • 从头到尾按题号背。
  • L3 题不准备 tradeoff。
  • 项目经历和八股脱节。

3 个自测问题

Context、Loop、Tool。

机制 + tradeoff + 监控 + 降级。

用知识工程项目连接 RAG/Context。

面试口述
