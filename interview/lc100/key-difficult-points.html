复习路线

先把 P0 主线讲顺，再补 P1 追问。每个点都要能落到“设计取舍、生产风险、如何验证”。

1. Context

管理指令、历史、工具结果、检索文档和成本。

2. Loop

讲清 Agent 为什么需要 Observation、预算和终止条件。

3. Tool/RAG

区分模型决策、工具执行、检索召回和结构化校验。

4. Runtime

Go 内存、GC、pprof；MySQL 日志恢复；Redis 持久化与锁。

5. Production

Eval、Observability、灰度、降级、安全和隐私。

1 到 2 分钟口述模板

我会先给结论，再说明核心机制，最后补生产取舍。比如讲一个 Agent 或中间件问题时，我会按四步展开：第一，它解决什么问题；第二，底层关键机制是什么；第三，生产里有哪些失败模式和监控指标；第四，结合项目我会如何落地，哪些细节还需要根据业务补充。
