## Promotion Voucher：代码可见的系统背景（B）

本地仓库 README 和代码表明，这是营销系统的优惠券核心服务：包含券组管理、券实例创建/发放/查询/试算/使用/回滚/过期，以及奖励规则、使用规则和外部业务接口。

### 可讲的系统链路

```text
运营后台配置券
-> 校验奖励/使用/领取规则
-> 券配置落库 + 外部券系统同步
-> 用户领取 / 发放
-> 试算可用性与规则
-> 用券 TCC Try + 用券记录
-> 异步结果通知 / 成功或回滚
-> Kafka / 可靠事件重试 / 审计与查询
```

代码依据包括：

- 管理端创建、更新、启停和删除券时有规则校验、状态校验、版本递增、审计记录及外部券服务同步。
- 用户侧存在 `TrialVoucher`、`UseVoucher`、`NotifyUseVoucherResult`、`RevertVoucher`、`DispatchVoucher` 等 RPC 入口。
- 用券记录以 `request_id` 和业务关联 ID 做唯一约束；券、用户券、用券记录更新均可使用 version 条件，体现幂等与乐观锁控制。
- 存在可靠事件 handler/consumer 的重试次数、下次执行时间、错误信息、状态、版本和去重键；调度任务会重试 producer 事件。

### 不能仅凭代码写成个人成绩的内容（C）
