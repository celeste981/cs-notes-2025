# 深圳目标岗位：初步市场扫描

> 扫描日期：2026-08-10。招聘信息变化很快；本页只用于确定准备优先级，不能视为可直接投递的岗位清单。投递前必须在公司官网或招聘平台确认岗位仍开放、地点、职级和业务线。

## 结论先行

当前信号支持“双轨但不对等”的策略：

- **主投：Senior Backend / Go Backend**。深圳岗位反复出现的要求与你已有经历高度重合：Golang、MySQL、Redis、Kafka、微服务、分布式系统、性能与可用性。
- **选择性投：AI 应用 / Agent Backend**。不少岗位会直接要求 Python 工程经验、LangGraph/LangChain、MCP、Agent 编排；其中“多 Agent / 框架源码级”不应成为三个月的硬目标。更合适的切入是强调后端工程化、Tool、异步任务、状态、RAG、可观测性和业务系统整合。

## 目标 JD 筛选规则

### P0：优先投递

- 深圳，3-6 年或 Senior Backend/Go Backend。
- 核心要求命中至少 60%：Go、MySQL、Redis、Kafka/MQ、RPC/微服务、分布式、高并发或复杂业务后台。
- 业务在金融、交易、营销、运营平台、企业服务、云服务或 AI 应用平台。

### P1：有选择地投递

- AI Application / Agent Backend，要求 LLM/Tool/RAG/Workflow，且接受“后端经验 + AI 实践”。
- Python 是要求但不是“多年 Python 主力开发 + 算法背景”。
- 能将个人项目和既有后端经验自然连接。

### 暂不优先

- 明确要求模型训练、后训练、算法论文、CUDA/GPU、SFT/RLHF 的岗位。
- 明确要求多 Agent 平台多年生产经验、Python 深度主力经验，且没有后端工程转化空间的岗位。
