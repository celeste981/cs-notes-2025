# AI 项目材料

这个目录用于沉淀 AI Agent、知识工程化、MCP、Skill、团队知识库等方向的项目背景、架构梳理和面试表达材料。

## 当前文档

- [Shopee Insurance 知识工程化总体规划设计](insurance-knowledge-engineering-plan.md)：根据截图整理的项目定位、架构分层、知识治理和 Agent 使用路径。
- [Agent Backend MVP：可信度优先的求职项目](agent-backend-mvp-plan.md)：推荐的唯一主项目；两周最小闭环、可选场景、停止规则与诚实面试表达。
- [Voucher Operations Agent：生产级 Agent Backend 项目设计](voucher-operations-agent-design.md)：面向 Promotion / Voucher 场景的求职作品项目，重点是 Workflow、Tool 治理、状态、审批、审计、评估和可靠性。
- [Agent 面试表达版](../../interview/agent/insurance-knowledge-engineering-interview.md)：把该项目转成 STAR、追问和可口述答案。

## 使用方式

- 新增 AI 相关项目材料时，优先放在本目录。
- 时间有限时，优先完成 `agent-backend-mvp-plan.md` 的必做范围；`voucher-operations-agent-design.md` 仅作可选业务扩展。
- 面试复习时先看项目定位、个人可讲贡献、架构价值和待补充事实。
- 未确认的项目事实统一标记为 `待补充`，不要直接写进简历。
