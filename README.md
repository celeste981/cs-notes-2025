# Interview Prep Workspace

这个项目用于持续沉淀求职面试材料：面试题、面试记录、岗位 JD、简历内容、项目经验和复习笔记。

## 目录

- [career-transition-plan.md](career-transition-plan.md)：三个月双岗位（Senior Backend + AI Agent Backend）求职定位、节奏和产物。
- [reviews/three-month-weekly-plan.md](reviews/three-month-weekly-plan.md)：适合在职准备的逐周计划、验收与缩减规则。
- `interview/`：技术题、行为题、算法题、系统设计题和专题复习。
- `resume/`：简历版本、简历 bullet 优化、JD 匹配结果。
- `projects/`：项目架构、项目亮点、STAR 故事、可讲案例；先从 [`projects/README.md`](projects/README.md) 或 [`projects/project-map.html`](projects/project-map.html) 进入。
- `templates/`：常用整理模板。
- `reviews/`：模拟面试反馈、复盘记录、阶段性问题清单。

## 推荐工作流

1. 把原始材料发给 Agent，不需要先整理得很干净。
2. Agent 先判断材料类型：题目、面经、JD、简历、项目经历或知识点。
3. 按 `templates/` 中的结构整理成可复习 Markdown。
4. 对每道题保留三层内容：
   - 30 秒短答
   - 1 到 2 分钟标准回答
   - 可应对追问的深入解释
5. 对项目和简历内容，默认检查真实性和可追问性，缺失事实标记为 `待补充`。

## 文件命名

- 技术题：`M1-01-query-flow.md` 这种编号式命名，沿用已有 MySQL 风格。
- JD 匹配：`company-role-jd-match.md`。
- 面试复盘：`yyyy-mm-dd-company-round-review.md`。
- 项目故事：`project-name-star-stories.md`。

## 复习优先级

- P0：必须背熟，简历或目标岗位高频相关。
- P1：需要理解，面试中可能被追问。
- P2：扩展加分项，时间充足时复习。
